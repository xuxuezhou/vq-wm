# VQ-WM project page

Project page for **Vector-Quantized World Model: Latent Feedback Motion Planning for Robot Manipulation**
(Xuezhou Xu, Chung-Pang Wang, Zhenzhen Li, Benjamin Riviere; submitted to ICRA 2027).

- `index.html` – the page
- `style.css` – styles (light and dark theme)
- `assets/` – figures cropped from the paper and the paper PDF

The site is static. Serve the repository root (for example with GitHub Pages) or open `index.html` directly.

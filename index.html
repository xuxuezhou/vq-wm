VQ-WM

Vector-Quantized World Model:
Latent Feedback Motion Planning for Robot Manipulation

Xuezhou Xu*1, Chung-Pang Wang*1, Zhenzhen Li2, Benjamin Riviere1

1New York University  ·  2NVIDIA  ·  *Equal contribution

Paper (PDF) Paper (arXiv) Code — coming soon Video — coming soon

Visual world models have shown strong potential for robot planning, yet long-horizon manipulation remains challenging: prediction errors compound over autoregressive rollouts, search complexity grows with the horizon, and planners propose latent targets that the low-level controller cannot reliably reach. We introduce VQ-WM, a latent feedback motion planning framework that vector-quantizes the latent space by controller reachability, measured as first-passage time, so a discrete planner can search far ahead over reachable states while a continuous controller tracks each planned state with visual feedback.

Method

Discrete search over controller-reachable states, executed with visual feedback

Planning slow

Breadth-first search over vector-quantized states with the discrete predictor PQ returns the shortest code path from qinit to qgoal. One call plans about five minutes of robot execution in under a second.

Control fast

A goal-conditioned controller π(· | zt, qi) tracks each planned code every step from visual feedback, for the number of calls the first-passage-time estimate assigns to that transition.

First-passage time d(z, z′): the number of controller calls until a closed-loop rollout of π in the learned latent model first reaches z′. It replaces Euclidean distance for building the codebook and assigning states, so every code is a target the controller can actually reach.

Training

  1. Controller π

    Goal-conditioned, trained on state–goal pairs up to R steps apart with an L1 action loss.

  2. Latent predictor PZ

    Supervised on closed-loop rollouts with π, the same procedure used to estimate first-passage time.

  3. State codebook Q

    Greedy set cover over estimated regions of attraction; each state maps to the code it reaches in the fewest calls.

  4. Discrete dynamics PQ

    Action codebook and code-to-code predictor learned jointly from code transitions with cross-entropy and VQ losses.

Ablation

First-passage time vs. Euclidean distance for state quantization

Simulated Tower of Hanoi, same encoder, controller and training; only the quantization metric changes.

  • First-passage time peaks near 90% success; Euclidean distance peaks at 40%.
  • High success holds across codebook sizes from about 250 to 2000, an eightfold range.
  • Euclidean codes ignore reachability and switch targets on latent proximity, so plans stall or skip ahead.
